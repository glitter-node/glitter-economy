# Glitter Economy

Glitter Economy is a Gnuboard7 module for shared ledger-based virtual value infrastructure.

The module is designed to support community points, ecommerce rewards, auctions, attendance rewards, advertising rewards, commissions, credits, and future wallet-like use cases.

This bundled source contains the pre-install domain, service, repository, migration, and initial HTTP API boundaries. Layout JSON, module lifecycle commands, and actual migration execution remain intentionally deferred.

See `docs/initial-design.md` for the initial ledger design.
